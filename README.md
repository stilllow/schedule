# Расписание занятий

Статический сайт без сборки: открывается как есть, публикуется на GitHub Pages.
Данные и вход — Supabase.

## Структура

```
index.html        каркас страницы и список подключаемых файлов
config.js         ключи Supabase (создаёте сами, в репозиторий не меняется при обновлениях)
fonts/            шрифты
css/              стили по слоям: 01-base → 02-glass → 03-layout → 04-components → 05-extras
js/               код по темам, подключается строго по порядку номеров:
  01-core         настройки, состояние, даты, модель занятий
  02-data         тема, загрузка и сохранение профиля
  03-views        экраны: сегодня, расписание, задания, настройки, render()
  04-dialogs      окна занятия, отмены/замены, задания
  05-events       глобальные обработчики
  06-weather      виджет времени и погоды
  07-i18n         переводы RU/EN, язык, масштаб
  08-ui           аватар, ползунок масштаба, аккаунт, выпадающие списки
  09-electives    факультативы
  10-insights     пересечения, «окна», сводка недели, напоминания о заданиях
  11-guide        подсказки для новых пользователей
  12-calendar     экспорт .ics, ссылка для просмотра, публичная страница
  13-importer     импорт из текста, CSV, Excel, PDF, фото
  14-app          напоминания и запуск
tests/            автопроверки (npm test)
migration_*.sql   изменения базы данных, выполняются по порядку в Supabase → SQL Editor
```

## Как обновлять

1. Замените файлы в репозитории (index.html, css/, js/). `config.js` и `fonts/` не трогайте.
2. Если в обновлении есть новый `migration_*.sql`, выполните его в Supabase.
3. Если браузер показывает старую версию, обновите страницу с очисткой кэша (Ctrl+F5).

## Проверки

`npm test` (нужен Node.js 20+) проверяет синтаксис всех файлов и прогоняет экраны и логику
в «пустом» окружении. На GitHub это происходит само при каждой загрузке файлов (вкладка Actions).
Проверки не открывают настоящий браузер: внешний вид и работу распознавания фото/PDF нужно смотреть вручную.
